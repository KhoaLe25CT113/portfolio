# Portfolio Cá Nhân - Lê Văn Khoa

Trang web hồ sơ năng lực & portfolio hiện đại dành cho vị trí **Software Engineer & Data-Driven Developer**.

## ✨ Điểm nổi bật
- **Giao diện hiện đại (Dark Theme & Glassmorphism)**: Tối ưu trải nghiệm thị giác với hiệu ứng chuyển màu và ánh sáng mượt mà.
- **Tự chứa hoàn toàn (Self-contained)**: Toàn bộ hình ảnh cá nhân và tài nguyên được tối ưu nhúng Base64, hiển thị hoàn hảo ở mọi thiết bị mà không phụ thuộc vào đường dẫn cục bộ.
- **Tối ưu hiển thị đa nền tảng**: Responsive hoàn chỉnh trên Máy tính, Máy tính bảng và Điện thoại thông minh.
- **Hỗ trợ in ấn / Xuất file PDF**: Tích hợp nút in CV chuẩn A4 nhanh chóng.

## 🛠️ Công nghệ sử dụng
- **HTML5 & CSS3** hiện đại (CSS Variables, Flexbox, CSS Grid, Glassmorphism).
- **JavaScript ES6+** xử lý tương tác mượt mà.
- **Google Fonts**: Inter & JetBrains Mono.

## 🚀 Cách sử dụng
Mở trực tiếp tệp `index.html` trên bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari).
